# Aloft Dedicated Server - AMP Configuration Template

An unofficial configuration template for deploying and managing an Aloft Dedicated Server
inside CubeCoders AMP.
Optimized for containerized environments (Podman / Docker) running Windows 64-bit executables under Wine.

*Steam Account with Aloft needed for Instalation*

## Managing Files
After setup and first run, you can Upload your own worlds under `Data06/Saves/`
